# How we work here (compound engineering)

Every unit of work should make the next one easier. The full guidance lives in **`CLAUDE.md`**; read it. The essentials for any agent (Claude, Cursor, or otherwise):

- **Loop:** Plan → Work → Review → Compound. Plan into `docs/plans/`; review with the specialized agents in `.claude/agents/`; capture every non-obvious lesson into `docs/solutions/` (searchable, YAML frontmatter) or an ADR in `docs/decisions/`.
- **Non-negotiable invariants:**
  - Every economic number (cpp, miles, price, verdict) is computed by `lib/*` — **never** generated by an LLM. Agents narrate computed values; they don't invent them.
  - Graceful degradation: persistence goes through `lib/supabase-helpers.ts#withDb`; clients return `{ok:false}`/fallbacks and **never throw**.
  - New seams ship **flag-gated** (`lib/env.ts`) and degrade to a clean no-op when unconfigured.
  - Copy voice is strict (`docs/design/copy-spec.md`): terse, state the number, no marketing slop, no emoji.
- **Read before you change a decided area:** `docs/decisions/`. **Search before you solve:** `docs/solutions/`.
- The **`eve/`** directory is the Eve agent (a separate Vercel Eve runtime), deliberately excluded from the Next app's typecheck/lint/build — do not add it to the build graph (`eve/README.md`).
- **Teach the system, don't just do the task.** When you learn something durable, write it where the next agent will find it automatically.
